{% comment %} Navbar clock modal. Ports the standalone clock page (clock.html) into a Bootstrap modal. All of the original CSS is scoped under `.mes-clock` so the page-level rules it used -- `:root`, `*` and `body` -- cannot leak into the rest of the app. Every element id is prefixed with `mesClock` to avoid clashing with other pages. The animation only runs while the modal is open: it starts on `shown.bs.modal` and is cancelled on `hidden.bs.modal`, so a closed clock costs nothing. {% endcomment %}
